Using the API

Include the client once, then call functions or embed pages. Everything is static and served by GitHub Pages.

<script src="{{public_url}}api/v{{version}}/pp.js"></script>
<div id="demo"></div>
<script>
  // Compute
  PP.call("{{module_id}}", "solve", 1, -3, 2).then(console.log);

  // Embed an interactive page (auto-sized iframe)
  PP.embed("#demo", "{{page_id}}", {{example}});

  // Style your own markup with the shared theme + components
  PP.useTheme("portfolio");
</script>

Machine-readable listing: api/v{{version}}/manifest.json
